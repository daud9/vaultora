# Security Policy

VAULTORA is an early development project intended for Stellar Testnet. It is not a production vault and must not be used to protect real documents or secrets.

## Reporting a vulnerability

Please do not open a public issue for an exploitable vulnerability. Report it privately to the repository owner through GitHub's private vulnerability reporting feature when available. If that feature is unavailable, contact the maintainer through a private channel linked from the GitHub profile. Include affected commit or component, impact, and safe reproduction steps. Redact credentials, personal data, document contents, and recovery material.

Please allow time for triage and a fix before public disclosure. This policy is not a promise of a response time or bounty.

## Scope and current limitations

The in-scope code is the source in this repository. Testnet contracts, test accounts, test XLM, and temporary deployment metadata have no production value. Do not probe unrelated networks, accounts, or services. No production service or guardian recovery system is currently claimed.
